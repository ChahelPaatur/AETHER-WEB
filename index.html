Fault recovery

It catches its own faults.

A PPO network reads a 15-channel sensor vector on every step and names the fault as it happens. Recovery puts the robot back in a safe state.

Guards that don't learn

Motion always ends in a stop.
Every motion tool stops in a finally block; unbounded adapters are refused.
One stop reaches every thread.
A global stop and a motor lock span every worker.
Nothing runs as root.
A sudo blocker refuses every shell-out.
Drones need five yeses.
Arm permission, pre-arm check, live sensors, 30 s idle disarm, e-stop.

Models

Bring your own model.

Drop in an API key. AETHER discovers your sensors and motors, and the model plans against the live capability manifest. Claude is the default; OpenAI, Gemini, DeepSeek and Kimi plug in through the same provider block.

PRIMARY · ACTIVE

Claude API recommended.

The default integration. Aether ships pre-wired for Anthropic's Claude. Best results for tool-grounded code generation, multi-step planning, and JSON-mode calls against the discovered capability manifest. Sonnet is the recommended model for most rigs.

# ~/.aether/config.toml
provider = "anthropic"
model    = "claude-sonnet-4-6"
api_key  = "$ANTHROPIC_API_KEY"
max_tokens = 8192

01 / KEY
Drop in your API key.

Export it as an environment variable or write it into the Aether config. Every provider reads from the same block, so switching models is one line.

$ export ANTHROPIC_API_KEY=...
02 / DISCOVER
Aether builds the manifest.

Run calibration once. Aether probes USB, I²C, GPIO, MAVLink, and on-device models, then writes a capability manifest that grounds every prompt.

$ aether --calibrate
03 / PROMPT
Type what you want.

The prompt, the manifest, and the FDIR constraints are sent together. The model returns code. FDIR wraps that code on execution and keeps it safe.

$ aether do "patrol the room"

Up in three commands.

Python 3.9 or newer on Linux, macOS or Raspberry Pi OS. Sim mode needs no robot and no API key.

View on PyPI Quick start →
~ — zsh 
$ pip install aether-robotics
$ aether --calibrate   # walk GPIO pins, label actuators
$ aether --mode agent  # plain-English control, live hardware
