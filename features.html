Docs/Concepts

Features

Plain-English control

Type an objective; the planner turns it into tool calls.

Auto-discovery

A GPIO calibration walk maps every actuator by pin.

Portable genome

One robot.json runs on every matching robot.

Auto-adapters

Tier 1/2/3 — has a Python library? AETHER can drive it.

Parallel skills

Drive and sense at once behind a shared stop event.

DRL-first FDIR

A PPO net classifies faults and recovers in real time.

Drone + ground

MAVLink flight controllers through the same interface.

Lightweight

Runs on a Raspberry Pi 4 — no GPU required.
