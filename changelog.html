Version history

VersionChange
5.10.1A detector that cannot run raises instead of returning “nothing seen”; a watcher refuses to start rather than examine a hundred frames with a broken one. MediaPipe Tasks API supported alongside solutions.
5.10.0Continuous local sensing: conditions a local sense can decide are watched at ~10 Hz instead of iterated through an LLM.
5.9.1 – 5.9.5MediaPipe hands as a local geometric tier — 21 landmarks, finger counts, gestures — plus the routing fix that made it actually get called, and deterministic verdicts used directly rather than handed to a model to judge.
5.9.0Vision-driven pursuit: a goal can watch until it sees something.
5.8.1 – 5.8.6Capability gating (tools register only when the hardware answers a real probe), a [vision] extra that announces itself, the camera path on every platform, and describe_scene no longer reported as a fault when it succeeded.
5.8.0SAM 3 open-vocabulary detection via a hosted GPU endpoint: pixel masks, centroids, bearings and cross-frame identity.
5.7.0Vision through the existing provider abstraction — describe_scene on any vision-capable provider.
5.6.xTurn provenance, drive-rate calibration, proactive avoidance; stall detection that does not kill diagnosis.
5.5.0Obstacle recovery, position held through failure, sensor power-sag diagnosis.
5.4.xClosed-loop goal pursuit for autonomous mode; AETHER_HOME for every store.
5.3.0Angle-accurate turning, continuous operation, sensor-sweep rendering.
5.0 – 5.2Multi-provider LLM abstraction with free tiers; capability gating, security hardening and the plan cache.
4.5.xParallel autonomous execution with hard safety guards; reactive and observational sensing.
4.3.0Vector retrieval over persistent memory, behind the [rag] extra.
4.2.0Full-screen Textual TUI.
4.1.xLocal analytics with opt-in telemetry, behind a consent gate on every entrypoint.
4.0.0Autonomous mode: LLM goal decomposition and the execution loop.
3.9.5Universal sensor-noise fix: drive_until_obstacle halts on consecutive bad reads, not a lifetime count — tolerates motor-EMI bursts.
3.9.4Turn default 1.0 → 2.0 s; boot-time ultrasonic health probe + richer wiring guidance.
3.9.3Continuous-motion primitives eliminate jitter; pulsed fallback for non-SunFounder adapters.
3.9.1Latency skip on clean multi-step objectives; approach-speed curve.
3.9.0Parallel execution layer; drive_until_obstacle skill.
3.7.xAuto-adapter system + the SunFounder safety chain.
3.6.0MAVLink quadcopter integration with five arming rules.

Roadmap

  • ✓ Phase 1 — Reverse engineering: GPIO pin walk, physical_map, LLM control.
  • ✓ Phase 2 — Robot Genome: versioned robot.json, deterministic capabilities.
  • ✓ Phase 3 — Auto-adapter system: Tier 1/2/3; offline generation.
  • ✓ Phase 4 — Vision-language grounding: four perception tiers (camera/VLM, YOLO, MediaPipe hands, SAM 3) and continuous local sensing.
  • Phase 5 — Operational memory + sim-to-real action transfer.
  • Phase 6 — Multi-robot coordination.
